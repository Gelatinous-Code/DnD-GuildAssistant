# Code of Conduct

## Our standard

We want this project to be a welcoming place for people of every background and
experience level. Be respectful, assume good intent, accept constructive
feedback, and keep criticism focused on ideas and code rather than people.

Harassment, discrimination, threats, sexualized attention, deliberate
intimidation, doxxing, or sustained disruption are not acceptable. Do not share
another person's private information or private guild content without explicit
permission.

## Scope

This standard applies in repository spaces and whenever someone represents the
project in public, including issues, pull requests, reviews, discussions, and
community events.

## Reporting and enforcement

Report conduct concerns privately to a project maintainer. Do not use a public
issue when doing so would expose a target or sensitive details. Maintainers will
review reports in good faith, protect privacy where practical, and may edit or
remove content, warn participants, restrict participation, or permanently ban
people whose behavior is harmful to the community.

If a maintainer is involved in the concern, report it to another Gelatinous Code
maintainer.
